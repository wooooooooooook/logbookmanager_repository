## 1. 새로 시작하기 및 규칙 선택

Logbook Manager는 각 병원 및 학회의 기준(규칙)에 따라 판독목록을 읽고 자동으로 분류합니다.

1. 메인 화면에서 **🚀 새로 시작하기** 카드를 클릭합니다.
2. **사용자 이름**: 본인의 이름을 입력합니다 (저장 파일명 및 보고서에 표시됩니다).
3. **규칙 선택**: 기본으로 선택되어 있는 **ML 규칙 (기본값 권장)**을 그대로 사용하세요.
   - **ML 규칙 (추천)**: 전국 수련병원의 방대한 검사명 패턴을 학습한 온디바이스 AI 엔진이 자동으로 검사종류와 세부전공을 판별하므로, 복잡한 병원별 규칙 설정 없이도 가장 높은 정확도를 제공합니다.
   - 본인 병원 전용으로 정밀하게 맞춘 YAML 규칙이 있거나 규칙 조건식만으로 분류하고 싶다면 해당 병원 규칙을 선택할 수도 있습니다.
   - [규칙 작성법 (고급 가이드)](/docs/1._규칙파일_작성_가이드)
4. **판독목록 선택**: PACS 등에서 추출한 판독목록 엑셀(.xlsx) 파일을 선택합니다.
   - [판독목록 준비하는 방법](/docs/판독목록_준비하기)

> 💡 **빠른 둘러보기**: 메인 화면의 **🎯 데모 체험하기**를 클릭하면 별도 파일 없이도 샘플 데이터와 온디바이스 ML 모델로 전체 기능을 즉시 체험할 수 있습니다.

## 2. 자동 분류 및 분류 방식 선택

판독목록 파일을 불러오면 브라우저 내에서 즉시 고속 자동 분류가 수행됩니다.

사이드바 하단에서 분류 방식을 선택할 수 있습니다:

- **ML 분류 (기본 권장)**: 온디바이스 머신러닝 모델을 활용하여 복잡하고 다양한 검사명을 높은 정확도로 자동 분류합니다.
- **기존 규칙**: YAML에 정의된 조건식만을 사용하여 엄격하게 1:1 매칭합니다.
- [AI 분류 안내 상세 보기](/docs/AI_분류_안내)

## 3. 분류 결과 확인 (대시보드)

분류가 완료되면 **대시보드** 화면으로 자동 이동합니다.

- **전체 목표 달성률**: 학회 전공의 수련 목표 대비 현재 판독 건수와 누적 달성률을 확인할 수 있습니다.
- **카테고리별 현황**: 흉부, 복부, 근골격, 신경두경부 등 세부전공별 달성 현황을 확인합니다.
- **월간/주간/일일 누적 그래프**: 기간별 판독 추이를 그래프로 분석할 수 있습니다.
- **AI 분류항목 검토**: AI 분류를 사용한 경우, 사이드바의 검토 메뉴에서 확신도가 다소 낮은 항목을 확인하고 필요 시 [수동 분류 노하우](/docs/AI_분류_안내#4-로그북-목표-달성을-위한-필수-수동-분류-노하우)에 따라 카테고리를 보정할 수 있습니다.

## 4. 프로젝트 저장하기 (중요 ⭐️)

Logbook Manager는 사용자의 소중한 판독 정보와 개인정보를 **외부 서버로 전송하거나 보관하지 않고 오직 사용자의 브라우저 로컬에서만 처리**합니다.

따라서 작업을 마친 후에는 반드시 **왼쪽 사이드바의 💾 프로젝트 저장** 버튼을 클릭하여 프로젝트 파일(`.json.gz`)을 다운로드받아 PC에 보관해 두세요.

다음번에 방문했을 때 이 파일을 불러오면 기존 작업 내역과 수동 분류 내역이 그대로 복원됩니다.

## 5. 데이터 내보내기 (대한영상의학회 로그북 사이트 업로드)

판독기록을 대한영상의학회 로그북 사이트에 업로드합니다.

학회 사이트는 입국 연도에 따라 두 곳으로 나뉩니다:

- **2022년 이후 입국**: [대한영상의학회 e-portfolio (record2)](https://record2.radiology.or.kr/)
- **2021년 이전 입국**: [대한영상의학회 전공의 수첩 (record2020)](https://record2020.radiology.or.kr/)

### 내보내기 절차

1. 왼쪽 사이드바의 **📤 데이터 내보내기**를 클릭합니다.
2. **데이터 기간 필터링**: 이전에 업로드한 기간과 겹치지 않도록 업로드할 기간을 설정합니다.
3. **내보내기 형식 선택**:

#### 방법 A: 판독기록1 직접 등록 (추천 ⭐️)

일일이 사이트에서 클릭할 필요 없이, Logbook Manager가 생성해 주는 자동 등록 자바스크립트 코드를 이용해 1초 만에 전체 등록합니다.

![코드 복사 화면](/imgs/upload_code.png)

1. 내보내기 화면에서 **판독기록1 직접 등록**을 선택하고, 화면에 생성된 코드를 **코드 복사** 버튼으로 복사합니다.
2. 학회 로그북 사이트에 로그인 후, **판독기록1 > 직접 등록** 팝업창을 엽니다.
3. 키보드의 **F12**를 눌러 브라우저 개발자 도구를 열고, **Console(콘솔)** 탭으로 이동합니다.
4. ![콘솔 붙여넣기](/imgs/paste_to_console.png)
5. 콘솔 입력창에 복사한 코드를 붙여넣고 **Enter(엔터)**를 누릅니다.
   - ⚠️ 크롬 브라우저에서 `붙여넣기를 허용하려면 아래에...` 경고가 나오는 경우, 안내대로 `붙여넣기 허용`을 입력하고 엔터를 친 뒤 다시 코드를 붙여넣으세요.
6. 학회 사이트 판독기록1 목록에서 정상적으로 숫자가 채워졌는지 확인합니다.

- [판독기록1 직접 등록 방법 상세 가이드](/docs/판독기록1_직접_등록_방법)
- [기존 학회 판독기록을 초기화하고 새로 올리고 싶다면?](/docs/record2020_사이트_판독기록1_초기화)

#### 방법 B: 판독기록1 CSV 업로드

대량의 원본 판독 행 데이터를 CSV 파일로 직접 업로드하는 방식입니다.

1. 내보내기 화면에서 **판독기록1 CSV**를 선택하고, **CSV 내보내기** 버튼을 눌러 파일을 다운로드합니다.
2. 학회 로그북 사이트의 **판독기록1 > CSV 업로드** 메뉴에서 해당 파일을 업로드합니다.

---

## 6. 다음번에 추가 판독목록을 등록할 때

![프로젝트 불러오기](/imgs/project_load.png)

1. 메인 화면에서 **💾 저장파일 불러오기** 카드를 클릭하거나, 기존에 저장해 둔 프로젝트 파일(`.json.gz`)을 드래그하여 불러옵니다.
2. 화면 오른쪽 상단의 **📁 데이터추가** 버튼을 눌러, 지난번 등록 이후 새롭게 판독한 엑셀 파일을 추가로 불러옵니다.
3. 분류 결과 확인 및 데이터 내보내기를 동일하게 진행합니다.
4. 작업 완료 후 다시 **💾 프로젝트 저장**으로 최신 상태를 백업해 두세요!
