# 🤖 AI 자동 분류 및 검토·수동 분류 완벽 가이드

Logbook Manager는 전공의 선생님들의 판독목록 정리에 드는 시간을 획기적으로 줄이기 위해 **브라우저 로컬에서 초고속으로 동작하는 온디바이스 머신러닝(ML) 모델**을 기본 탑재하고 있습니다.

외부 서버로 판독 데이터를 전혀 전송하지 않고 사용자의 PC 브라우저 안에서만 안전하게 동작하며, 수만 건의 비정형적이고 다양한 검사명을 높은 정확도로 자동 분류합니다.

---

## 1. 왜 ML 분류가 기본인가요?

과거의 단순 문자열 규칙(YAML 매칭) 방식은 검사명에 특정 단어가 정확히 일치해야만 분류할 수 있었습니다.
예를 들어 `Chest PA`, `Chest_PA`, `chest (portable)`, `Chest 1 view`처럼 병원마다 표기가 조금만 달라도 일일이 규칙을 추가해야 했고, 미분류가 대량으로 발생하는 문제가 있었습니다.

### 온디바이스 ML 분류의 핵심 장점

1. **유사 표현 자동 인식**: 검사명을 다차원 벡터로 변환하여 학습된 수만 건의 임상 데이터 패턴을 바탕으로 가장 적합한 세부전공/검사종류 카테고리를 찾아냅니다.
2. **개인정보 유출 원천 차단**: 판독 엑셀을 외부 서버나 클라우드로 업로드하지 않고, 순수 브라우저(WebAssembly / ONNX Runtime) 메모리에서만 연산합니다.
3. **초고속 실시간 처리**: 수천~수만 건의 데이터도 수초 안에 분류를 완료합니다.

---

## 2. 분류 방식 (ML 분류 vs 기존 규칙)

왼쪽 사이드바 맨 아래에서 분류 방식을 확인할 수 있습니다:

| 분류 방식               | 동작 방식                                                            | 추천 사용 시점                                         |
| :---------------------- | :------------------------------------------------------------------- | :----------------------------------------------------- |
| **ML 분류 (기본 권장)** | 온디바이스 AI 모델로 자동 분류합니다.                                | **일반적인 모든 판독목록 정리 시**                     |
| **기존 규칙**           | 선택한 규칙 YAML 파일의 조건식(문자열 대조)만으로 엄격히 분류합니다. | 특정 병원 전용 규칙의 1:1 매칭 결과만 확인하고 싶을 때 |

> 💡 **안내**: 두 방식 모두 검사명·검사일 등 필수 정보가 누락된 행은 동일하게 '데이터 보완 필요'로 안전하게 감지합니다.

---

## 3. AI 분류항목 검토 화면 200% 활용하기

AI가 높은 확률로 분류한 항목은 자동으로 통계에 반영되지만, 모델의 확신도(Confidence Score)가 기준선보다 다소 낮거나 병원 고유의 특수한 약어가 사용된 항목은 사람이 직접 확인할 수 있도록 **AI 분류항목 검토** 메뉴를 제공합니다.

사이드바의 `AI 분류항목 검토` 메뉴에 숫자 뱃지가 표시되어 있다면 검토할 항목이 있다는 뜻입니다.

### 검토 상태 탭

- **🔍 검토 필요**: AI 확신도가 낮아 확인을 권장하는 항목들입니다.
- **⚡️ 자동 승인**: AI의 확신도가 충분히 높아 검토 없이도 신뢰할 수 있는 항목들입니다.
- **✅ 승인 완료**: 사용자가 직접 확인하고 승인 버튼을 누른 항목들입니다.
- **✏️ 수동 지정**: AI 추천 대신 사용자가 다른 카테고리로 직접 변경한 항목들입니다.

### 검토 화면 추천 작업 흐름

1. **중복 묶음 보기**: 같은 검사명이 수십 건씩 반복된 경우, `중복 묶음` 모드로 설정하면 동일 검사를 한 번의 클릭으로 일괄 승인하거나 지정할 수 있어 작업 시간이 대폭 단축됩니다.
2. **비교 및 지정**: AI가 추천한 카테고리와 현재 적용된 카테고리를 비교하고, 만약 다른 세부전공이어야 한다면 `지정` 버튼을 눌러 올바른 카테고리로 즉시 변경합니다.
3. **선택 일괄 승인**: 확인이 끝난 항목들은 체크박스로 선택 후 `선택 항목 승인`을 누르면 완료됩니다.

## 4. 수동 분류 방법 및 학회 공식 교차 배정 기준

Logbook Manager는 전공의 선생님들이 수련 목표를 효율적으로 달성할 수 있도록 **앱 내 카테고리 이동 모달**과 **대한영상의학회 공식 지침 기반의 교차 배정 가이드**를 탑재하고 있습니다.

### 수동 분류는 어떻게 진행하나요? (앱 내 조작법)

1. **카테고리 이동 모달 열기**:
   - `전체 데이터 조회`, `카테고리별 상세`, `AI 분류항목 검토`, `미분류 항목` 등 데이터 테이블이 있는 모든 화면에서 해당 행의 **`✎ 이동`** 버튼 또는 카테고리 배지를 클릭합니다.
2. **목적지 카테고리 선택**:
   - 이동하고자 하는 카테고리를 선택하면, 해당 카테고리가 다른 세부전공에서 인정받을 수 있는 항목인 경우 **앱이 학회 공식 '교차 배정 가이드'를 모달 상단에 자동으로 안내**해 줍니다.
3. **동일 패턴 중복 항목 일괄 이동**:
   - 모달 하단에 현재 데이터 내에서 동일한 검사명/패턴을 가진 후보 행들이 자동으로 검색되어 나타납니다. 함께 이동할 항목들을 체크하여 한 번의 클릭으로 일괄 이동할 수 있습니다.
4. **수동 분류 내역 모아보기**:
   - 수동으로 이동한 모든 항목은 사이드바의 **`✏️ 수동 분류 항목`** 메뉴에서 언제든지 한눈에 확인하고 관리할 수 있습니다.

---

### 학회 공식 지침에 따른 대표적 교차 배정(수동 분류) 기준

대한영상의학회 전공의 수첩 지침에 따라 아래의 검사들은 다른 카테고리에서 판독을 가져와 부족한 수련 목표량을 채울 수 있습니다:

| 목표 카테고리                                         | 가져올 수 있는 출처 (검사 종류)                                | 학회 공식 인정 기준 및 팁                                                                                                                                                                                                     |
| :---------------------------------------------------- | :------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **인터벤션 > 대퇴동맥천자술**<br/>(필수 최소 1건)     | 뇌혈관 조영술 (TFCA)<br/>선택적 혈관조영술 (TACE, UAE, BAE 등) | 대퇴동맥천자술 단독 검사명은 없으므로, 혈관조영술 중 전공의가 대퇴동맥천자를 직접 시행한 건을 **최소 1건 이상 대퇴동맥천자술로 수동 이동**해야 학회 필수 조건을 충족합니다.                                                   |
| **비뇨생식기 CT**                                     | 복부 CT (CT abdomen and pelvis)                                | 복부 CT 검사명이 세분화되지 않은 병원의 경우, **신장내과·비뇨의학과·산부인과**에서 처방된 복부 CT는 비뇨생식기계 CT로 인정됩니다.                                                                                             |
| **혈관 CT**                                           | 심장 CT<br/>흉부 CT                                            | • 대동맥 박리(Dissection) 평가 목적의 **Triple rule-out CT**는 혈관 CT로 인정됩니다.<br/>• 폐색전증과 하지정맥혈전증을 동시 평가하는 **Pulmonary artery + DVT CT**는 혈관 CT로 분류할 수 있습니다.                            |
| **도플러 초음파**                                     | 소아 초음파<br/>복부 초음파                                    | • 소아 뇌초음파(Brain US with Doppler) 중 **뇌혈관(Intracranial vessel) 평가**가 주목적인 검사는 도플러로 분류 가능합니다.<br/>• 복부에서 시행한 **간/신장이식 또는 신동맥 협착 도플러 초음파**는 도플러 항목으로 인정됩니다. |
| **소아 검사 전체**<br/>(일반촬영 / CT / MRI / 초음파) | 각 부위별 일반(성인) 검사 전체                                 | 각 부위별 일반 카테고리에 분류된 검사 중 **소아 환자(병원 기준 통상 15~19세 이하)** 검사는 소아 카테고리로 이전 배정할 수 있습니다. (단, 양쪽 중복 카운트는 불가)                                                             |
| **신생아 흉복부 (infantogram)**                       | 흉부 일반촬영 / 복부 일반촬영                                  | 생후 3개월 이내 신생아·영아의 흉부와 복부를 함께 촬영한 검사는 **소아 일반촬영(infantogram)**으로 인정됩니다.                                                                                                                 |
| **비뇨기계 초음파**                                   | 소아 초음파                                                    | 소아 카테고리에 분류된 검사 중 **소아 고환 초음파(Scrotal US)** 등 비뇨기 검사는 비뇨기계 초음파로 배정할 수 있습니다.                                                                                                        |
| **시술 (초음파 유도하 생검 등)**                      | 유방촬영 / 유방 검사                                           | 유방 검사 중 단순 영상 판독이 아닌 **위치결정술(Localization), 침생검(Biopsy)** 등은 '시술' 카테고리로 배정해야 합니다.                                                                                                       |

---

### 수동 분류 데이터의 영구 보존 원칙

- 직접 수동 지정한 항목은 이후 규칙을 재적용하거나 AI 재분류를 실행하더라도 **기본적으로 절대 덮어씌워지지 않고 영구 보존**됩니다.
- 규칙 재적용 창에서 `수동 분류 항목 초기화`를 의도적으로 체크한 경우에만 수동 분류가 해제되고 재분류 대상에 포함되므로 안심하고 작업하실 수 있습니다.

---

## 5. 수동 분류 피드백과 프라이버시 보호 (재학습 기여)

사용자께서 잘못된 AI 분류를 올바른 카테고리로 `수동 지정`해 주신 내역은, 향후 Logbook Manager AI 모델을 더 똑똑하게 재학습시키는 가장 가치 있는 피드백 데이터가 됩니다.

### 철저한 개인정보 비수집 원칙

Logbook Manager는 AI 학습 데이터 수집 시에도 **철저하게 민감정보를 걸러냅니다**:

- **절대 수집하지 않는 정보**: 환자 성명, 주민등록번호, 차트번호(MRN), 구체적 검사 일시, 의사 성명/사번, 판독문 원문
- **수집되는 정보**: 정규화된 검사명(예: Chest PA), 검사 장비 구분(CR/CT/MR 등), 연령대 범주(성인/소아), 사용자가 수정한 최종 카테고리 ID

> 사용자는 데이터 수집 동의 여부를 언제든지 선택할 수 있으며, 동의하지 않더라도 웹앱의 모든 기능은 아무런 제약 없이 100% 무료로 정상 동작합니다.
