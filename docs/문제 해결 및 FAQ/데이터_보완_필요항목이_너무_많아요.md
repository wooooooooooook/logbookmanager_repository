# 데이터 보완 필요항목이 너무 많아요

`데이터 보완 필요` 카테고리는 규칙에 지정된 필수 정보(예: 판독일자, 환자 나이, 검사종류, 판독실 등)가 원본 엑셀 파일에서 빈 칸이거나 잘못 기재되어 분류를 완료할 수 없을 때 발생합니다.

Logbook Manager는 원본 엑셀을 다시 열지 않고도 **앱 내에서 수십~수백 건의 누락 데이터를 한 번에 채울 수 있는 `일괄 수정` 기능**을 지원합니다.

---

## 방법 1. 앱 내 '일괄 수정' 기능 활용 (가장 추천)

수십 건 이상의 동일하거나 유사한 누락 항목을 한 번에 입력하고 재분류할 수 있습니다.

1. **대상 행 선택**:
   - `카테고리별 상세 > 데이터 보완 필요` 화면으로 이동합니다.
   - 표 헤더의 체크박스를 클릭하여 현재 목록의 전체 행(또는 수정할 특정 행들)을 선택합니다.
2. **`✏️ 일괄 수정` 버튼 클릭**:
   - 테이블 상단 툴바에 나타나는 **`✏️ 일괄 수정`** 버튼을 클릭합니다.
3. **수정할 필드와 값 입력**:
   - 보완할 필드(예: `나이`, `판독일`, `검사종류(Modality)`, `판독실` 등)를 선택합니다.
   - 값을 입력하면 앱이 기존 데이터 기반의 자동 완성 추천 목록을 제공합니다.
   - 여러 필드를 동시에 추가하여 한 번에 일괄 수정할 수도 있습니다.
4. **미리보기(Diff) 확인 및 적용**:
   - **`미리보기`**를 클릭하면 수정 전/후 값의 변화와 함께 **어떤 카테고리로 자동 재분류될지** 사전에 시뮬레이션 결과를 보여줍니다.
   - 확인 후 **`일괄 적용`**을 누르면 모든 행의 데이터가 즉시 갱신되며 올바른 카테고리로 자동 이동합니다.

---

## 방법 2. 단건 직접 수정 (건수가 적은 경우)

- 보완이 필요한 행을 더블클릭하거나 행 우측의 `수정` 버튼을 누르면 단건 편집 모달이 열립니다.
- 비어 있는 항목에 올바른 값을 입력하고 저장하면 즉시 재분류됩니다.

---

## 방법 3. 원본 엑셀 수정 후 재업로드 (엑셀 작업이 편한 경우)

대량의 데이터를 엑셀 함수나 필터로 정제하는 것이 더 익숙하다면 아래와 같이 진행하실 수도 있습니다.

1. `데이터 보완 필요` 카테고리의 항목들을 전체 선택하여 **삭제**합니다.
2. 원본 엑셀 파일에서 필수 항목이 빈 칸인 행들을 찾아 올바른 값을 채워 넣고 저장합니다.
3. 앱 상단 바의 **`데이터 추가`**를 눌러 수정한 엑셀 파일을 업로드합니다.
4. 이미 등록되어 있는 정상 판독 건들은 고유번호 기준으로 자동 중복 제외되며, 삭제했던 보완 대상 검사들만 새로 정상 분류되어 등록됩니다.
