# AI 분류 안내

Logbook Manager는 기본적으로 **브라우저 안에서 동작하는 머신러닝 모델**로 판독 목록을 자동 분류합니다.
모델이 브라우저에서 실행되므로, 판독 목록을 서버로 보내지 않고 내 컴퓨터에서만 처리됩니다.

이 문서는 AI 분류를 켜고 끄는 방법, 모델을 고르는 방법, AI가 애매하게 분류한 항목을 검토하는 방법, 그리고 모델 개선에 협조하는 방법을 설명합니다.

## 분류 방식 두 가지

왼쪽 사이드바 맨 아래에 분류 방식 탭이 있습니다.

| 탭                 | 동작                                                                                 | 언제 쓰나                                 |
| ------------------ | ------------------------------------------------------------------------------------ | ----------------------------------------- |
| `ML 분류` (기본값) | 브라우저에서 AI 모델로 분류합니다. 필수 입력값이 비어 있는 데이터는 먼저 걸러냅니다. | 대부분의 경우                             |
| `기존 규칙`        | 선택한 규칙 파일의 YAML 조건만으로 분류합니다.                                       | 규칙만으로 분류 정확도를 확인하고 싶을 때 |

두 방식 모두 **미분류 항목과 데이터 보완 필요 항목은 동일하게 발생**합니다. 차이는 그 이후의 자동 분류 정확도입니다.

### ML 분류가 정확도에서 유리한 이유

기존 규칙 방식은 검사명에 특정 문자열이 들어가는지를 순서대로 대조하는 방식이라, 병원마다 표현이 다른 검사명("Chest PA", "Chest_PA", " chest ")을 모두 규칙에 적어야 합니다. ML 분류는 검사명을 수치로 벡터화해 유사한 이름을 자동으로 묶기 때문에, 규칙으로 열거하지 않은 표현도 그에 가장 가까운 카테고리로 분류됩니다.

반대로 **ML 분류는 데이터가 어느 병원의 것인지에 따라 편차가 있습니다.** 특정 병원의 판독실 표기를 학습하지 못했다면 그 항목이 미분류로 나올 수 있고, 이럴 때는 `기존 규칙` 탭으로 전환해 해당 규칙으로 재분류한 뒤 AI 분류 항목 검토에서 확인하는 방식이 유용합니다.

## 분류 모델 선택

`ML 분류` 탭에서 모델 이름 버튼(기본적으로 `모델: 기본값`)을 누르면 **분류 모델 선택** 팝업이 열립니다.

- **프로덕션**: 승인된 모델만으로 구성된 번들입니다. 실제 작업에는 이쪽을 사용하세요.
- **평가 전용**: 아직 승격되지 않은 후보 모델입니다. 분류 결과가 실제 운영 기준과 다를 수 있으니 **비교용도로만** 사용하세요.

번호가 적힌 여러 모델 후보가 보이는데, 각 후보는 `Context`(검사명을 보고 검사종류·세부전공 후보를 좁히는 모델)와 `General`(최종 카테고리를 결정하는 모델)로 구성됩니다. 어떤 후보를 고르든 팝업 하단에 선택한 번들이 표시되고, `모델 적용`을 눌러야 실제 분류에 반영됩니다.

사이드바의 모델 이름 옆에 `평가 추론` 배지가 붙어 있다면, 현재 평가 전용 모델이 적용된 상태라는 뜻입니다. 실제 로그북 작업 중에는 프로덕션 모델로 되돌려 두는 편이 안전합니다.

## 데이터 추가 후 재분류

새 판독 목록을 추가하면 추가된 행만 자동 분류됩니다. 전체를 다시 분류하고 싶다면 해당 영역의 `재분류` 버튼을 누르세요.

규칙을 편집하거나 다른 규칙으로 바꿨다면 `ML 분류` 탭의 `재분류`, `기존 규칙` 탭의 `재적용` 버튼으로 다시 분류합니다. 분류 결과는 **기존 수동 분류를 덮어쓰지 않습니다.** 직접 지정한 항목은 그대로 유지되므로, 재분류 후 차이가 생긴 항목만 검토하면 됩니다.

## AI 분류 항목 검토

AI가 확신하지 못한 항목은 검토가 필요합니다. 왼쪽 사이드바의 `AI 분류항목 검토`에서 확인할 수 있고, 검토할 항목이 쌓여 있으면 메뉴에 숫자 배지가 표시됩니다.

### 검토 상태 탭

| 탭             | 내용                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------ |
| `검토 필요`    | AI 확신도가 낮아 사람의 확인이 필요한 항목                                                       |
| `자동 승인`    | 확신도가 충분히 높아 그대로 통과한 항목                                                          |
| `승인 완료`    | 직접 확인하고 승인한 항목                                                                        |
| `수동 지정`    | AI 추천과 다른 카테고리로 직접 지정한 항목                                                       |
| `전체 AI 대상` | 위 네 상태를 모두 포함. ML 추천과 현재 적용 카테고리가 다른 항목만 남기는 필터를 쓸 수 있습니다. |

`검토 필요` 항목이 많다면 일단 `자동 승인` 항목도 함께 살펴보며, 확신도가 낮아도 실제 분류가 맞는 경우가 많습니다.

### 검토 화면에서 할 수 있는 일

- **보기 방식**: `중복 묶음`으로 같은 검사명이 반복된 그룹을 한 번에 보거나, `전체`로 한 줄씩 볼 수 있습니다. 같은 검사가 여러 번 들어온 경우를 빠르게 찾을 때 유용합니다.
- **검색**: 데이터 상세 화면과 같은 검색 카드를 그대로 사용합니다. 검사명, 부서, 판독실 등으로 좁혀서 볼 수 있습니다.
- **상세**: 각 항목의 모든 컬럼 값을 펼쳐서 확인할 수 있습니다. AI 추천 카테고리와 현재 적용된 카테고리를 나란히 비교하는 용도입니다.
- **승인**: 선택한 항목의 분류를 확정합니다. 여러 항목을 선택한 뒤 한 번에 승인할 수 있습니다.
- **지정**: 다른 카테고리로 직접 지정합니다. 카테고리 이동 모달에서 목적지를 고르면 됩니다. 이 항목을 AI가 틀렸다고 알려주는 피드백이 됩니다.
- **삭제**: 해당 항목을 데이터에서 삭제합니다. 로그북에 해당하지 않는 행입니다.

> 검토 결과는 나중에 집계되는 AI 개선 데이터로도 쓰입니다. 다음 절의 재학습 데이터 내보내기를 참고하세요.

## 재학습 데이터 내보내기와 동의

직접 지정한 결과는 AI 모델의 약점을 찾아내는 데 값어치가 큽니다. Logbook Manager는 이 피드백을 활용하되, **전송 여부는 사용자가 고릅니다.**

### 처음 등장하는 동의 안내

수동 분류를 처음 진행할 때 **수동분류 데이터 수집 안내 및 동의** 창이 뜹니다.

- **수집되는 항목**: 정규화된 검사명(예: Chest PA), 검사 장비 구분(CT/MR/CR 등), 진료과 및 판독파트, 연령대 범주(17세 미만/이상으로 범주화), 사용자가 확정한 최종 카테고리 ID, 기존 AI/규칙 예측과 확신도(오차 분석용)
- **절대 수집하지 않는 항목**: 환자 성명 및 주민등록번호, 환자 등록번호/차트번호(MRN), 구체적인 생년월일 및 검사 일시, 의사/검사자 성명 및 사번, 판독 소견서 및 진료기록 원문

엑셀 원본을 읽는 단계부터 위의 민감 정보는 메모리에 올리지도 수집하지도 않습니다.

### 동의하지 않았을 때

분류 기능은 아무 제약 없이 정상 동작합니다. 동의하지 않은 상태에서는 `수동 분류 항목` 화면에 `📥 재학습 데이터 내보내기 (.csv)` 버튼이 나타납니다. 눌러서 CSV로 내려받은 뒤, 직접 확인해서 원하는 경우에만 전달하면 됩니다.

### 동의했을 때

동의하면 별도 조작 없이 모델 개선에 사용됩니다. 동의 여부는 나중에 설정에서 바꿀 수 있습니다.

## 요약

- 기본값은 `ML 분류`이고, 모델은 브라우저에서 실행됩니다.
- 모델은 `프로덕션` 번들을 사용하세요. `평가 추론` 배지가 보이면 실제 작업 전 프로덕션으로 되돌리세요.
- 확신도가 낮은 항목은 `AI 분류항목 검토`에서 확인하고, 다른 카테고리라면 `지정`해 주세요.
- 모델 개선 데이터 전송은 선택이며, 거절해도 기능 제한은 없습니다. 직접 내보내기로 대신할 수 있습니다.
